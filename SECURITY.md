# Security policy

## Supported versions

Security fixes are provided for the current v1 release line. Users should reproduce a report on
the latest compatible release before submitting it when that can be done safely.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting flow for this repository when it is available. Do
not place secrets, workstation inventory, private snapshots, or exploit details in a public
issue. If private reporting is unavailable, open a public issue containing only a request for a
private maintainer contact and no sensitive technical detail.

Include the affected RigPilot version, the public interface involved, expected behavior, and a
minimal privacy-safe reproduction. RigPilot has no telemetry service, so maintainers cannot see
local failures unless you choose to report them.

Ordinary bugs and documentation errors that contain no sensitive information may use the public
issue tracker.
